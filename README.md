# LinkedIn AI Governance Article Cover Video

Professional 30-second video for LinkedIn article cover featuring AI governance messaging.

## Video Specifications

- **Format**: MP4 (H.264 codec)
- **Resolution**: 1920 x 1080 pixels (16:9)
- **Frame rate**: 30fps
- **Duration**: 28 seconds
- **File size**: 243KB
- **Audio**: Silent (optimized for auto-play)

## Scene Breakdown

### Scene 1 (0-3s): The Hook
- Text: "Your board can't govern AI."
- Purpose: Attention-grabbing opening

### Scene 2 (3-9s): The Problem
- Text: "Traditional oversight models FAIL at AI speed."
- Purpose: Establish the challenge

### Scene 3 (9-16s): The Stakes
- Text: "Risk moves faster than quarterly reviews."
- Visual: Simple upward trending line graph
- Purpose: Make the urgency tangible

### Scene 4 (16-24s): The Shift
- Text: "Boards need new muscles. Not more meetings."
- Purpose: Signal a different approach

### Scene 5 (24-28s): The CTA
- Text: "Read the full framework ↓"
- Purpose: Direct action

## Design Style

- **Visual aesthetic**: Clean, corporate (McKinsey/BCG style)
- **Background**: Dark (#1a1a1a) with subtle gradients
- **Typography**: Sans-serif, high contrast white text
- **Emphasis**: Red (#ef4444) for critical messaging ("FAIL")
- **Motion**: Minimal, professional transitions

## Files

- `linkedin_ai_governance_video.mp4` - The final rendered video
- `generate_video.py` - Python script to generate the video
- `video_assets/` - Directory for intermediate assets

## Usage

To regenerate the video:

```bash
python3 generate_video.py
```

## Requirements

- Python 3.11+
- moviepy
- pillow
- numpy

Install dependencies:
```bash
pip3 install moviepy pillow numpy
```
